# Numeric targets

TargetNumber and target/result Dashlets separate an editable target from an application-owned actual result. The application computes results and status. Target controls do not implement a solver.

Implementation: [source](../../packages/dashstack/src/target-number.tsx). Public names and signatures: [API inventory](../reference/api/index.md).
