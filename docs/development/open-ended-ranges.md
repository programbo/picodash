# Open-ended ranges

Slider and Range options support labelled endpoint detents distinct from regular numeric steps. A detent is a domain value, not an infinite numeric endpoint. Read the exported option types and the detent tests before configuring one.

Implementation: [source](../../packages/dashstack/src/detent-slider.tsx). Public names and signatures: [API inventory](../reference/api/index.md).
Examples and behavior checks: [consumer fixtures](../../packages/picodash/tests/dogfood).
