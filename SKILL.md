# Working with Picodash

Start at [the current documentation](docs/index.md), choose a [package reference](README.md), and use public package imports.
`@picodash/dashpanel` owns placement, `@picodash/dashstack` owns composition, and `@picodash/picodash` integrates them.
Consumer task skills live with their packages. [Nexus](docs/reference/nexus.md) documents actual state APIs;
[the audit](docs/design/nexus-api-audit.md) records proposed improvements separately.
