# @picodash/picodash

Read the current [Picodash reference](https://github.com/programbo/picodash/blob/main/docs/reference/picodash.md) and [complete public API](https://github.com/programbo/picodash/blob/main/docs/reference/api/picodash.md).

This workspace builds version `0.0.0`; APIs may change before a stable release.
Run `bun run check`, `bun run test`, and `bun run build` from this package.
For installation use [local packages](https://github.com/programbo/picodash/blob/main/docs/development/local-packages.md) or [portable bundles](https://github.com/programbo/picodash/blob/main/docs/development/dogfooding.md).

Previous README versions are [archived](https://github.com/programbo/picodash/blob/main/docs/archive/2026-11-13/README.md).
