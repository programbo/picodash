# Contributing

Install with `bun install --frozen-lockfile`. Read [AGENTS.md](AGENTS.md) and the owning package reference before changing behavior.
Use public package entrypoints across packages. Build output is generated. Keep canonical state strict JSON and validate candidate batches atomically.
Run the narrow owning checks, update behavioral docs and regenerate the API inventory after public changes.
See [testing](TESTING.md), [development](docs/development/index.md), and [the Nexus audit](docs/design/nexus-api-audit.md).
